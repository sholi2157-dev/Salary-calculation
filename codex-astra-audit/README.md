# חבילת הביקורת

התחלה: REPORT.md. מרשם מאוחד: findings.csv / findings.json. כיסוי פעולות: coverage.csv; מסעות: journeys.csv. פקודות ותוצאות: test-ledger.json; ראיות מקור: evidence/.

הדוח וכל הסברים בעברית. מזהי שדות טכניים, שמות כלים ופלטי תוכנות נשמרו כפי שהופקו. קבצי בדיקה עשויים להפנות לנתיבי /workspace/salary-audit; להרצה מחוץ לסביבה יש להציב snapshots של ה־SHAs המתועדים ולעדכן רק את נתיבי רתמת הביקורת. אין בחבילה תיקוני יישום.

אין ראיית UI חדשה או APK חדש מהביקורת. ראיות CI קיימות נבדלות מההרצות המקומיות. קבצי המקור המקוריים והפריסה לא שונו. דוחות main מוקדמים הוצאו מחבילת המסקנות כדי למנוע שיוך תקלות ישנות למועמד הנוכחי.
