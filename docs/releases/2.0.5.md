# 2.0.5 — שעות ודקות, ממשק נקי ופעמון עדכונים

- אפשר לבחור שעות או דקות ולשנות ספרה בודדת גם במשך ידני, בקבוצה ובקבלנות, כמו בשעון.
- הוסרו מהטפסים ומלוח הספרות הסברי הקלדה קבועים, דוגמאות מיותרות והנחיות לחיצה. שמות השדות, הנגישות והודעות שגיאה נשמרו.
- פתיחה וסגירה של עריכת משך בלי הקלדה משאירות את הדיוק המקורי של שעות שיובאו.
- באנדרואיד הוסרה הפעלת חלון עדכון אוטומטי. העדכון מופיע בכרטיס בפעמון, עם נקודה אדומה עד להתקנתו.
- זמינות עדכון נבדקת בשקט בחזרה לאפליקציה, בפתיחת הפעמון ובכל דקה כשהאפליקציה בחזית. כשאין חיבור, נשמר העדכון שכבר נמצא.
- ההתקנה מתחילה רק מבחירת המשתמש, דרך מתקין אנדרואיד, עם אימות הקובץ והחתימה הקבועה.
- הגרסה מצטברת: כוללת את כל שינויי 2.0.4, וניתן לעדכן אליה ישירות מגרסה קודמת בלי להתקין קודם את 2.0.4.

באתר: פתיחה ורענון מקבלים את הדף העדכני באותו קישור; אין כפתור עדכון, בדיקת עדכון או מספר גרסה בהגדרות. עדכון ברקע אינו מרענן טופס פתוח. העותק המקומי המלא נשמר לגלישה ללא חיבור.

כל שינויי 2.0.4 בשיתוף, העתקה, אקסל, סיכום חודשי עם סכומים, חישוב שעות, בחירת ימים וסינון היסטוריה נשמרו. פירוט: [2.0.4](2.0.4.md).

מצב אימות ופרסום מתועד ב־`docs/duration-and-update-bell-20261021.md` וב־`docs/current-state.md`.

באתר נשמר גם קיצור שעות שנבחר בזמן שלוח הספרות פתוח. גם קישור ההורדה החלופי, כשהבדיקה מול GitHub נכשלת, מפנה ישירות לקובץ 2.0.5 המאומת.
