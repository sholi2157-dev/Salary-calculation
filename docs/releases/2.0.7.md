# 2.0.7 — הסיכום החודשי בלי ספוילרים

- הסיכום החודשי נפתח ב-30 לחודש (ביום האחרון בחודש קצר יותר), ומופיע בדף הבית עוד 4 ימים. הראשון: אוקטובר 2026.
- אחרי זה הוא נשמר ב"הגדרות ← הסיכומים שלי" יחד עם כל הסיכומים הקודמים. הסיכום השנתי נפתח עם דצמבר.
- ההתראה פותחת ישר את הסיפור, ובפעמון היא מסומנת "חדש" עד שצופים בו.
- ניסוחים שונים לכל משתמש ולכל חודש, וניסוחים משלו לסיכום השנתי.
- שיתוף הסיכום שולח תמונה בלבד. כל מסך בסיפור אפשר לשתף כתמונה.
- ספירת התקנות אנונימית: פעם אחת לכל מכשיר, מזהה אקראי, גרסה וחדש/עדכון בלבד.
- כל המשמרות, הסכומים וההגדרות נשמרים.
