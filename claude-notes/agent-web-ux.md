# Web UX + accessibility, second pass (agent-web) — issue register

Scope: built web app `ux-audit/src/web/public` (local static server, synthetic seed from `tools/lib.cjs`), Chromium/Playwright. Only read the app code; nothing was written to any production site.
Scripts: `ux-audit/tools/agent-web/{kb,kb2,kb3,layout,errors,targets,wide}.cjs` and `grid.py`. Raw outputs: `notes/agent-web-kb.json`, `notes/agent-web-kb2.json`, `notes/agent-web-layout.json`. Screenshots: `shots/agents/web-*.png` (grids: `g-320.png`, `g-err.png`, `g-desk.png`, `g-tab.png`).
Source line refs are to `ux-audit/src/web/web/kis/*.js` (the same as public, except for the cache-busting in kis.css).
"Confirmed" means a script reproduced it or the code shows it outright. "Subjective" means a design judgement.

## P1 — fix before the web release

| ID | Issue | Type | Evidence | Recommendation |
|---|---|---|---|---|
| U-01 | **Reflow fails at 320 CSS px (WCAG 1.4.10).** On History the document is 350px wide (`docScrollW 350 > vw 320`), and the title, the "מוצג:" line and the week heads are cut at the right edge. In the editor the clock row and top bar get wider than the screen: the "קבוצה" pill, the "קבלנות" tab, the end time "00:30" and the total "₪200" are cut on the left. | confirmed | `notes/agent-web-layout.json` keys `w320-history` and `w320-editor`; `shots/agents/web-w320-history.png`, `web-w320-editor.png` (grid `g-320.png`) | Let `.title-row` on History wrap, or move copy/search into an overflow. Stack the two time boxes vertically below about 360px, or shrink the digits with `clamp()`. Add a 320px check to CI. |
| U-02 | **Sheets do not trap focus.** `sheet()` (ui.js:95-110) sets `aria-modal`, but nothing behind it is inert and there is no Tab loop. After the last item of the places sheet, Tab goes to BODY and then to the settings page behind it. In the confirm sheet over the editor ("לצאת בלי לשמור?"), Tab goes from "לצאת" into the editor's controls underneath. The info sheet goes to the page after one Tab. | confirmed | `agent-web-kb.json` keys `places-tab40`, `info-tab`, `confirm-tab` | Make the siblings `inert` while a sheet is open, as the editor (editor.js:250) and the story already do, or use `<dialog>.showModal()`. |
| U-03 | **Keyboard focus is lost on every redraw.** Pages, sheets and the editor rebuild with `innerHTML`. When Enter is pressed on these controls, focus falls to `<body>`: theme segment, default-currency segment, editor ₪/$, editor day buttons, the filters-sheet segments ("חודש"), "סימון כשולם", and the group-worker paid chip. The editor's focus restore only knows `data-f/testid/t/h/mode/cat` (editor.js:329). `.days` and `[data-cur]` have none of these. The 60 s `setInterval(render)` (app.js:132) and every `store.subscribe(render)` also drop focus from any card on Home or History. | confirmed | `kb.json` keys `theme-after-enter`, `settings-currency-after-enter`, `editor-cur-after-enter`, `editor-day-after-enter`, `refresh-focus` (before `recent-f`, after `BODY`); `kb3.cjs` output "filters after Enter on חודש: BODY" | After any re-render, put focus back on an element with the same `data-*` key. One generic helper (save a selector, then restore it) is enough. Skip the periodic render while `document.activeElement` is inside `#page`. |
| U-04 | **The recap story moves on by itself, and a keyboard user cannot pause it (WCAG 2.2.2).** It advances every 6 s (summary.js:57,89). It pauses only on a pointer hold. Space does not pause it: the slide went from hours to places. Each auto-advance replaces the DOM, so focus on "הבא" falls to BODY. Closing it does not return focus. With `prefers-reduced-motion` the CSS animations stop, but the auto-advance and the JS count-up still run. | confirmed | `kb2.json` keys `story-focus-autoadvance` (start `story-next`, after 6.5 s `BODY`), `story-space-pauses?`, `story-close-focus`; `layout.json` `reduced-motion.autoAdvanceStill: story-intro -> story-hours`, `countUp: true` | Add a visible pause/play button, and make Space/K toggle it. Turn auto-advance off under reduced motion (manual next only). Keep focus on the nav button after `draw()`. Restore focus to the opener on close. |
| U-05 | **A screen reader cannot hear the time value.** Each digit is a button labelled `"התחלה · ספרה 1"` (editor.js:315). The `aria-label` replaces the digit, so the reader says "start, digit 1" four times and never "20:30". The group has no label, and the hidden `key-sink` input is labelled only "שעת התחלה". Today the value is available only from the ruler slider's `aria-valuetext`. There are also 8 tab stops for two times. | confirmed | `kb.json` key `editor-tab45`; markup at editor.js:313-316 | Make each time box one control, e.g. `role="group" aria-label="התחלה 20:30"` with one focusable spinbutton/input (`aria-valuetext`). Keep the per-digit tap for pointer users only (`tabindex=-1`, `aria-hidden`). |
| U-06 | **Errors are neither announced nor linked to fields, and some messages are wrong.** The save hint is a plain `<p>` (editor.js:323): not live, no `aria-invalid`, no `aria-describedby` (0 of each). If the rate is negative the hint says "הזן תעריף, או סמן "תעריף חסר"" although a rate was typed, and the total shows "₪-200". The hint tells the user to tick **"תעריף חסר"**, but that button reads **"לא יודע"** (editor.js:386 against rules.js:132). In the live-start sheet a rate of "-5" makes "התחלה" do nothing, with no message (app.js:87). | confirmed | `errors.cjs` output: `rate "-50" → hint "הזן תעריף…", meta "₪-200", invalid 0, describedby 0`; `live -5 → sheetStill true, invalid null` | Put the field error next to the field (`aria-invalid` and `aria-describedby`), and make the save hint `role="status"`. Write specific messages ("התעריף לא יכול להיות שלילי"). Make the hint's wording match the button label. Never show a negative total. |
| U-07 | **Invalid durations are changed silently, and implausible values are accepted.** In hours mode, typing 2-5-0-0 gives **20:00** and 9-9-9-9 gives **9:09**, with no message (desktop has no haptic). End 09:00 with start 10:00 is saved as a **23-hour shift** with no "למחרת"/overnight cue in the editor. A rate of `1e9` gives ₪4,000,000,000, and 99999.99 × 8 h is saved as **₪799,999.92**. There is no sanity confirmation and no `maxlength` on notes or place names. | confirmed | `errors.cjs` output; `shots/agents/web-err-overnight23h.png`, `web-err-bigamount.png`, `web-err-home-big.png` (grid `g-err.png`) | Refuse a digit with visible feedback ("שעה לא תקינה" inline). Show "למחרת · 23 ש׳" in the meta line when end ≤ start, and ask for confirmation above about 16 h. Add a soft confirmation above a plausible ceiling (e.g. a rate above ₪1,000/h). Cap notes (e.g. 500) and names (40, as profile names already are). |

## P2 — important

| ID | Issue | Type | Evidence | Recommendation |
|---|---|---|---|---|
| U-08 | The shift detail sheet has **no accessible name**: no `<h2>`, so `aria-labelledby` is null (app.js:40). Readers announce only "dialog". | confirmed | `kb2.json` `detail-name: {labelledby:null,label:null}` | Make the place name an `<h2>`, or set `aria-label`. |
| U-09 | Every shift card is a **toggle button** (`aria-pressed="false"`) even on Home, where there is no selection (ui.js:79). Readers say "toggle button, not pressed" for a control that opens details. | confirmed | `kb.json` `struct-home.shiftAriaPressed: 4`, History 13 | Output `aria-pressed` only while selection mode is active on History. |
| U-10 | The editor mode buttons have `role="tab"` **and** `aria-pressed` (the axe critical issue). They also have no `aria-controls`/tabpanel, all three have `tabindex=0`, and arrow keys do nothing. Other segmented controls use `aria-pressed`, so the pattern is inconsistent. | confirmed (refines pass-1 axe) | `kb2.json` `editor-tablist: ["null ti=0"×3]`, `editor-tab-arrowkey` (focus did not move) | Remove `role=tablist/tab` and use `aria-pressed`, like `.seg`. Or build a full radiogroup with roving tabindex. |
| U-11 | The ruler `role=slider` reacts only to Left/Right (RTL-mapped). Up, Down, Home, End, PageUp and PageDown do nothing. The 52×28 handle is below the target-size minimum. The places-sheet drag grip is a `span` with `aria-label` and has no keyboard alternative. | confirmed | `kb2.json` `ruler-arrow` (Right then Up moved −15 only); editor.js:596; pass-1 axe `aria-prohibited-attr` | Map Up=+15, Down=−15, PageUp/PageDown=±60, Home/End. Add move-up/down buttons (or a menu) for reordering places. |
| U-12 | The **toast** is a `role=status` host that is toggled `hidden`, with its content injected at the same moment (ui.js:84-89). Newly unhidden live regions are often not announced. The undo action ("ביטול") disappears after 6 s, and keyboard focus has no route to it (it is last in the DOM, after the nav). | confirmed (markup); announcement is likely, not tested with a real SR | `kb2.json` `toast-region {role:status, hidden:true}` | Keep the live region always in the DOM, visually hidden when idle. Pause the timer on hover/focus, and offer Ctrl+Z or move focus to the toast action for undo. |
| U-13 | **Undo and confirmation patterns are inconsistent.** Deleting from detail has no confirmation but has undo. Deleting from the editor and bulk delete have a confirmation **and** undo. Cancelling a live shift has a confirmation **and** undo. Marking one shift paid has **no feedback at all** (the sheet closes, no toast, focus goes to BODY). Bulk "שולם" shows a toast with no undo. The group-worker "לא שולם" chip closes the whole sheet on every tap (app.js:69), so marking 3 workers takes 6 taps. | confirmed | `kb2.json` `after-paid {focus:BODY, toast:none}`; `kb3.cjs` output "after worker paid chip: sheet open = 0", "bulk paid toast: סומן כשולם ✓" (no action) | Use one rule: reversible actions get an undo toast and no confirmation. Destructive bulk actions get one confirmation. Paid toggles show "סומן כשולם · ביטול". Keep the detail sheet open after a worker toggle and redraw it in place. |
| U-14 | The UI **ignores the user's font-size setting**. kis.css has 0 `rem`/`em` font sizes (243 `px`). Setting `html{font-size:24px}` gives a byte-identical screenshot. Browser zoom works (640px = 1280@200%: no overflow, a good result), but people who raise the default font size get nothing. | confirmed | `layout.json` `rootfont {identicalScreenshot:true}` | Move type tokens to `rem`, starting with body, captions, amounts and buttons. |
| U-15 | **Focus is invisible on the hidden inputs.** "בחירת קובץ" (import) and "תאריך אחר"/"עד" (editor) are `opacity:0` inputs inside a label. The ring is drawn on the transparent input, and there is no `:focus-within` rule. The same inputs add duplicate tab stops (the date input appeared twice in the editor tab run). | confirmed | `kb3.cjs` output `inputOpacity 0, labelOutline none, focus-within rule: false`; `shots/agents/web-kb-file-focus.png` | Add `label:has(input:focus-visible){outline:3px solid var(--glow)}`, or use a real button that calls `showPicker()`. |
| U-16 | **The editor needs too many keyboard stops.** From open to the rate field: close, group, 3 modes, "+ מקום", 9 place chips, 8 digits, 4 nudges, 2 sliders, 7 days, 2 date inputs, ₪/$. That is **about 40 Tab presses** before the rate. With no skip or roving focus, a keyboard user adding a shift goes through all of it. | confirmed | `kb.json` `editor-tab45` | Use roving tabindex (one stop per group: modes, places, days, currency). Merge each time into one stop (see U-05). |
| U-17 | **Touch targets below 44 px not in the pass-1 census:** filters-sheet segments, 14 controls all **38 px** tall. Editor modes and place chips 40 px tall. Nudges ±15 at 69×36 (390) / 112×36 (1280). Ruler handles 52×28. Weekday buttons 43×48. Date inputs 42 tall. | confirmed | `targets.cjs` output (`filters`, `editor-more-repeat`) | Set `.seg button`, `.chip` and `.nudges button` to min-height 44. Pad the ruler handles to 44×44 hit areas. |
| U-18 | **Mixed Hebrew grammatical registers.** Masculine imperative in errors and buttons: "הזן תעריף", "בחר מקום עבודה", "בחר שעת התחלה", "סמן", "הוסף לפחות אדם", "נסה שוב" (×4 account.js), "לא יודע", "כמה אתה הרווחת", "זה הכול. אתה מוכן.", "אני מתחיל עכשיו", "ברוך הבא". Neutral plural present in hints: "מוסיפים", "לוחצים", "מתחילים", "יוצרים", "פותחים". Second-person plural in the recap: "אתם בשטח", "סיימתם", "שלכם", "בקשו". Touch-only wording on desktop: "נגיעה לבטל", "נגיעה להזנה", "לחיצה ארוכה". | confirmed (grep) | rules.js:110,120,123,132; editor.js:152,157,359,361,386; home.js:70,79; launch.js:13; app.js:47; summary.js:37,65,69; account.js:140,180,261,280 | Use one voice. The neutral infinitive or noun forms the app already uses for buttons fit best: "יש להזין תעריף", "צריך לבחור מקום", "עוד לא ידוע", "התחלת משמרת עכשיו", "שלום". Replace "נגיעה" with "לחיצה", or drop it and use a real toggle. |
| U-19 | **Inconsistent terms and formats.** "דו״ח למעסיק" and "העתקת **דוח** הצוות" sit side by side in the same sheet (app.js:54; 1× דו״ח, 5× דוח overall). The filter says "**ממתין**" where cards and bulk actions say "**לא שולם**". Places are called "מקום", "מקום עבודה" and "מקום ברירת מחדל". Durations appear as "4:00 שעות" (editor), "6 ש׳" (week heads), "65.25 שעות" (totals) and "9:09" (typed). Dates: UI "4.11", shared text "04/11/2026" (share.js:9), account "4.11.2026" (`toLocaleDateString`). Inside Hebrew strings, straight `"…"` quotes ("תעריף חסר", "חוזרת כל שבוע", ב"מתוכנן") sit next to 17 uses of ״. "הכל" appears once (settings.js:175) against "הכול" 8 times. | confirmed (grep) | see file:line refs | Write a short glossary (דו״ח, לא שולם, מקום עבודה, H:MM ש׳) and apply it in one pass. Use ״ and the Hebrew quotes "…" consistently. |
| U-20 | **Desktop layout.** The app name appears twice (sidebar brand **and** the Home header "שכר עבודות אישי"). Content widths differ between pages: Home about 1016 px, History 796 px, editor 560 px, Settings 2-column. The Home hero ₪300 leaves a large empty block. Sidebar 230 px is mostly empty. The planned 4.11 shift appears side by side in "הבא בתור" **and** "אחרונות" (confirms W15). | confirmed + subjective | `shots/agents/s-d1440-home.png`, `s-d1440-history.png`, `g-desk.png` | Hide the Home header brand when the sidebar is visible. | U-21 | **Escape while typing a time** ends typing but leaves focus on BODY (the sink is blurred and nothing is refocused). The same fix as U-01 covers the editor. |

## Pass-1 items rechecked
- **W7** (duration formats): confirmed and extended in U-19 (also "9:09" from typing, "6 ש׳" week heads).
- **W8** (three search dismiss controls): confirmed. The native `::-webkit-search-cancel-button` computes `display:block` (`kb2.json` `search-native-cancel`).
- **W15** (planned shift in both lists): confirmed on desktop as well (`s-d1440-home.png`).
- **W19** (summary card on empty search): confirmed by code. `history-total` is always rendered (history.js:79).
- Pass-1 axe `aria-allowed-attr` on the mode buttons: confirmed. The root cause is the role=tab misuse plus missing tab behaviour (U-10).
- Partly **refuted:** zoom at 1280@200% (640 px) and WCAG 1.4.12 text spacing at 390 showed **no** overflow or clipping beyond the intended ellipsis (`layout.json` `z200-1280-*`, `ts390-*`). CSS transitions and keyframe animations **are** turned off under reduced motion (kis.css:243,272,273,358). Only the JS-driven motion (story auto-advance, count-up) is not (U-04).
