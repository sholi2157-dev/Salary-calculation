# Salary Calculation / חישוב שכר

A Hebrew, right-to-left wage and shift tracker for Android and the web.

## Project tracks

The default branch contains the original project baseline. For current work:

- Android: `claude/v2-android`.
- Website: `codex/download-and-management-20261020`.
- Published Android packages: the repository's GitHub Releases page.

The application supports recording work shifts and tracking earnings. Current
tracks include currency-aware summaries, backups, and release/update workflows.
Refer to the instructions and current-state documents on the relevant branch
before building or contributing; branch behavior and build requirements differ.

## Privacy and contribution guidelines

The source-code license grants rights to the project's software. It grants no
access to user records, accounts, credentials, signing material, or services.
Do not commit personal wage records, real user backups, secrets, or private
contact details. Use synthetic examples and test data. Keep provider keys and
signing credentials outside source control.
